Version <span style={{color: "#2a9d8f", fontWeight: "bold"}}>2.11.0</span> of plumio is here!

{/* truncate */}

This release includes:

### Major highlights

- Added <span style={{color: "#2a9d8f", fontWeight: "bold"}}>basic PWA support</span> for offline usage. Users can now view the files that have been opened while online. No write operations are supported while offline yet.
- Added <span style={{color: "#2a9d8f", fontWeight: "bold"}}>font size support</span> in the editor.

### Minor highlights

- Sidebar can be collapsed to save space.

### Security

- Updated dependencies to fix security vulnerabilities.

Thank you for using plumio! 🎉
